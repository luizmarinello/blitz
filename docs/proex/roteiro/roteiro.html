Respostas rápidas para as perguntas (os três devem saber)

PerguntaResposta curta
EC2 × Ubuntu × Nginx?EC2 é a máquina virtual da AWS; Ubuntu é o sistema operacional dela; Nginx é o programa servidor web que roda no Ubuntu.
Caminho de uma requisição?DNS → IP público → Security Group (443) → Nginx (TLS) → arquivo estático ou proxy para 127.0.0.1:8080 → Spring → PostgreSQL.
IP público × privado?Público (18.225.117.192) é o endereço na Internet; privado (172.31.10.255) só vale dentro da rede da AWS.
Por que limitar o SSH?Robôs varrem a Internet o tempo todo (aparece no nosso access.log). Com SSH só para IPs /32, ninguém de fora nem tenta a senha ou a chave.
Portas 22, 80, 443? E a 8080?22 = SSH (administração); 80 = HTTP (só redireciona); 443 = HTTPS. A 8080 é interna: só o Nginx, na mesma máquina, fala com ela.
Estático × proxy reverso?Estático: o Nginx lê o arquivo do disco e devolve. Proxy: repassa a requisição para outro programa (o Java) e devolve a resposta dele.
Terminal × systemd?Programa aberto no terminal morre quando o SSH fecha ou a máquina reinicia; o systemd inicia sozinho no boot, reinicia em falha e guarda os logs.
Reboot × stop/start?Reboot reinicia o sistema operacional e mantém o IP. Stop/start desliga a máquina, que pode voltar em outro hardware e com outro IP público.
Por que 502 com Nginx ativo?O Nginx está de pé, mas o programa para o qual ele repassa (Java na 8080) não respondeu.
Para que serve o access.log?Uma linha por requisição: quem, quando, qual caminho, qual código. Mostra se a requisição chegou e o que o servidor respondeu.
Como os segredos não vazam?Ficam só em /etc/blitz/blitz.env (640), gerados na instalação; o Git tem só um modelo com VALOR_OCULTADO; .pem e .env estão fora do repositório.
Git × backup?Git guarda o código, que é igual para todos; o backup guarda os dados que os usuários criaram, que só existem no banco.
E se o crédito acabar?A AWS suspende os recursos do plano gratuito. Por isso há backup fora da AWS e um plano de encerramento: exportar antes, desligar depois.
HTTP × HTTPS?Em HTTP, senha e cookie viajam legíveis; em HTTPS vão cifrados, e o certificado prova que o servidor é o dono do nome.
Limite de uma EC2 só?Sem redundância: se a máquina ou a zona cair, o sistema para. Alta disponibilidade exigiria duas instâncias, balanceador e banco com réplica.
